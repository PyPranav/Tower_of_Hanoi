# Tower of Hanoi Visualization

This is a Tower of Hanoi visualization webpage built using the Anime.js library. The visualization demonstrates the classic problem-solving process of moving disks between three pegs, following the rules of the Tower of Hanoi puzzle.

## Hosted Site

Check out the live version of the project <a href="https://pypranav.github.io/Tower_of_Hanoi/" target="_blank">Tower of Hanoi</a>.

## JavaScript Library

This project leverages the <a href="https://animejs.com/" target="_blank">Anime.js</a> library for creating smooth and visually appealing animations
